# Geode 3 audit, October 2026: bugs and AI slop

Read-only audit of `tessie1993/geode-3` at `190b8bd`. No code was changed.

**Method.** Eight parallel reviewers covered: playback/audio, native renderer/GL, audio analysis, export/Studio, data/imports, Compose UI, shaders/build/CI, and a cross-cutting "claims vs reality" pass. Each one traced user flows end to end with the Graphify code graph (callers, callees, references), then read the code on disk. Each also checked whether the items in `docs/AUDIT_2026-09.md` (written for the predecessor repo `geode-app`) still apply here. Findings that appeared in more than one area are merged below.

**Legend.**
- ✔ = re-verified in the code by the coordinating reviewer after the scan.
- Confidence, where stated: *confirmed* means traced in code; *likely* means the trace depends on platform or driver behaviour.
- Original reviewer IDs (PB, GL, AN, EX, DA, UI, BL, CX) are kept so each item can be traced back.

## 1. Executive summary

The C++ core is solid: the analysis DSP, frame graph, JNI/ABI surface, shader wiring, 16 KB page alignment and R8 keeps all check out. The default ExoPlayer path mostly works, and so do the MediaCodec/MediaMuxer pipelines.

The problems are at the seams, and in what the app *does* compared with what it *says*.

1. **State lives in the wrong place.** Playback settings, error-skip, history, resume position and A-B loop all live in the UI-scoped `PlayerSession`, not in the service. When music plays without the Activity (Bluetooth, Android Auto, app swiped away), those features stop. The most serious result: unplugging headphones keeps music playing through the speaker. A second MainActivity instance (any notification tap) tears that session down underneath the first.
2. **The latest commits are half-finished migrations.** R00 (MotionField) pinned every old beat/spike/spawn/form uniform to 0. It uploads 11 new uniforms that no shader reads, and adds a rotation term that accelerates and then snaps direction. Four Customize sliders now do nothing, and the five new motion dials have no UI. W11 ("export honours every lane") does not export the Visual or Overlay lanes, and it discards the skip report it builds. W00's overlay pass (about 420 lines) has no caller.
3. **What you see is not what you hear or export.** Live visuals run about 250 ms or more ahead of the audio. Hi-res (176.4/192 kHz) and mono AIFF exports drift by seconds to tens of seconds. Cached timelines differ from fresh ones. Project export closes timeline gaps, so clips placed later on a lane play from 0.
4. **Silent data loss.** A shared preset link opened on cold start can overwrite your own preset. Writing tags erases the file's COMMENT. Each sideload APK is signed with a new key, so updating means uninstalling, which loses all data.
5. **The opt-in native audio engine is not shippable.** It has no audio focus, no becoming-noisy handling and no advance when gapless is off. Queue identity is tracked by index. It uses two shuffle orders and has two use-after-free windows.
6. **Slop.**
   - About 31 MB of theme art and 30 sounds are bundled and never drawn or played.
   - About 1,000 lines of dead Kotlin mirror native code.
   - About 45 comments cite Kotlin files that were deleted.
   - The docs and CHANGELOG claim hundreds of tests; 3 test files exist (211 lines).
   - CI path filters skip C++-only changes entirely.
